# منصة ترتيل

نظام ويب عربي (RTL) لإدارة وتحفيز طلاب حلقات القرآن الكريم، بنظام النقاط والمكافآت التفاعلي والتحضير السريع من الهاتف.

## الأدوار

- **الطالب:** متابعة النقاط والإنجازات وسجل التقييم واستبدال المكافآت.
- **المعلم:** التحضير السريع وتقييم الطلاب يوميًا وملخص أسبوعي.
- **المشرف:** إحصائيات الحلقات والمتصدرين والطلاب المحتاجين للمتابعة وطلبات الاستبدال.
- **الإدارة:** إدارة الطلاب والمكافآت وقواعد النقاط وسجل التدقيق.

## التقنيات

- React 19 و TypeScript
- Vite و Tailwind CSS 4
- Firebase: المصادقة وقاعدة بيانات Firestore
- أيقونات lucide-react

## التشغيل محليًا

المتطلبات: Node.js 20 أو أحدث.

```bash
npm install
npm run dev
```

يعمل التطبيق على `http://localhost:3000`.

## الأوامر

| الأمر | الوظيفة |
| --- | --- |
| `npm run dev` | تشغيل خادم التطوير |
| `npm run build` | بناء النسخة النهائية في مجلد `dist` |
| `npm run preview` | معاينة النسخة المبنية |
| `npm run lint` | فحص الأنواع عبر TypeScript |

## هيكل المشروع

```
src/
  components/   admin, auth, common, student, supervisor, teacher
  context/      سياق المصادقة والإشعارات
  data/         البيانات الأولية (الحلقات والمعلمون والمكافآت)
  lib/          تهيئة Firebase
  services/     طبقة التخزين والمزامنة
  types/        الأنواع المشتركة
  utils/        التواريخ والنقاط
  assets/       الشعارات المستخدمة داخل الواجهة
public/branding/ أيقونة الموقع
branding/       الشعارات الأصلية
```

## إعداد Firebase

إعدادات Firebase للويب في `src/lib/firebase.ts`. مفتاح الويب معرّف عام وليس سرًّا، والحماية الفعلية تأتي من قواعد Firestore، فاحرص على ضبطها ونشرها من لوحة Firebase أو بـ `firebase deploy --only firestore:rules`.

## النشر

شغّل `npm run build` ثم ارفع محتوى `dist/` على أي استضافة ثابتة.
